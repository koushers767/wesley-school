Fourteen on-brand screens and emails, grouped by the alumni journey. Each closes a specific gap from the alumni research.

These are wireframes for discussion — sample data and placeholder copy. They're grouped by the alumni journey rather than a calendar, because a single feature (like Register) naturally spans several screens. A build sequence — without dates — is at the bottom of this page.

Build sequence

Suggested order of work

This shows priority and the order things get built — not a delivery timeline or dates.

  1. 1

    Phase 1 · Foundation

    Register, welcome email, profile and directory — capture alumni and give them a place to belong.

  2. 2

    Phase 2 · Network

    The connect & message loop — notifications, inbox and alert emails so alumni actually reach each other.

  3. 3

    Phase 3 · Give & attend

    Online giving with 80G receipts, and events with RSVP.

  4. 4

    Phase 4 · Run & measure

    Admin broadcasts and the dashboard — operate the association and track participation.

After sign-off, the foundation cluster (Register + welcome + profile + directory) is wired to a real backend first, then each phase follows in priority order.
